# MeshChatApp
OfflineMesh – Peer-to-Peer Offline Messaging for iPhone

OfflineMesh is a decentralized peer-to-peer messaging application built with SwiftUI and Apple’s Multipeer Connectivity framework. The app enables nearby iPhone devices to discover, connect, and exchange messages without requiring an internet connection, cellular network, or external server infrastructure.

The project focuses on creating a reliable offline communication system using local wireless technologies such as Bluetooth and peer-to-peer Wi-Fi. Devices automatically discover nearby peers, establish secure local connections, and maintain communication entirely offline.

Features

* Real-time offline messaging
* Nearby device discovery
* Peer-to-peer communication using Multipeer Connectivity
* Automatic local network connection handling
* SwiftUI-based modern iOS interface
* No internet or server dependency
* Secure local communication
* Lightweight and decentralized architecture

Tech Stack

* Swift
* SwiftUI
* MultipeerConnectivity Framework
* Combine
* MVVM Architecture
* Xcode

How It Works

1. The app advertises the device to nearby peers.
2. Nearby devices are discovered automatically.
3. Users can connect to nearby devices directly.
4. Messages are exchanged using local peer-to-peer communication channels.
5. Communication continues even without Wi-Fi routers or mobile data.
